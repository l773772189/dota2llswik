# 第 02 章：认识地图编辑器

> 这一章我们来认识 Hammer——Dota 2 的地图编辑器。你将学会怎么画地形、摆物件，这些操作全部都是鼠标点点就能完成的。

## 本章目标

完成本章后，你将：
- ✅ 熟悉 Hammer 编辑器的界面，知道各个区域是干什么的
- ✅ 会画地形：调整高低、刷不同的地面材质、加水域
- ✅ 会往地图上摆放树木、石头、建筑等物件
- ✅ 会生成导航网格（让游戏里的单位知道哪里能走）
- ✅ 能把地图编译出来并在游戏中加载
