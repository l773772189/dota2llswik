# 第 06 章：实现刷兵波次

> 敌人配置好了，但它们还不会自己刷出来。这一章我们要实现「一波一波自动刷兵」的功能。波次的内容全部通过配置文件定义，但让它们自动刷出来需要一小段脚本——别紧张，**你只需要复制粘贴就行**。

## 本章目标

完成本章后，你将：
- ✅ 用配置文件定义好每一波刷什么兵、刷多少
- ✅ 让游戏自动按波次刷出敌人
- ✅ 敌人刷出后会自动沿路线走向玩家基地
- ✅ 实现波次之间的间隔时间
