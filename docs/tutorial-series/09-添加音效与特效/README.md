# 第 09 章：添加音效与特效

> 游戏功能差不多了，但还缺少「感觉」。这一章我们给游戏加上音效和视觉特效，让攻击有打击感、技能有视觉冲击力。大部分工作是选择和配置现有的特效资源。

## 本章目标

完成本章后，你将：
- ✅ 给技能和攻击添加粒子特效（使用 Dota 2 自带的特效）
- ✅ 配置游戏中的音效（攻击声、技能声）
- ✅ 添加背景音乐
- ✅ 让游戏的视听体验更加完整
