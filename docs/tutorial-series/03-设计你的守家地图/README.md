# 第 03 章：设计你的守家地图

> 现在你已经会用地图编辑器了，这一章我们要正式开始设计一张守家类游戏的地图。我们会规划好基地在哪、敌人从哪来、沿什么路走。

## 本章目标

完成本章后，你将：
- ✅ 理解守家类游戏的地图应该包含哪些区域
- ✅ 搭建好玩家的基地和防守区域
- ✅ 画出敌人的进攻路线
- ✅ 设置好敌人出生点和路线上的拐弯点
- ✅ 给地图加上装饰，让它好看起来
