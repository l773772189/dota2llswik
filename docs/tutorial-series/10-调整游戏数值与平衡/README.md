# 第 10 章：调整游戏数值与平衡

> 游戏做完了，但好不好玩取决于数值平衡。太简单没挑战，太难玩不下去。这一章教你怎么通过调整配置文件中的数值，让游戏的难度恰到好处。全部是修改配置，不需要写代码。

## 本章目标

完成本章后，你将：
- ✅ 知道怎样让游戏不会太简单也不会太难
- ✅ 调整好敌人每波的强度增长节奏
- ✅ 让金币收入和花费达到合理平衡
- ✅ 配置好不同难度等级供玩家选择
