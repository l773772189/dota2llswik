# Dota 2 编辑器入门系列 —— 防守类游戏开发教程

> 本系列教程以制作一个完整的 **防守类（Survival/Defense）自定义游戏** 为目标，从零开始带你掌握 Dota 2 Workshop Tools 的核心功能。

## 适合人群

- 对 Dota 2 自定义游戏开发感兴趣的新手
- 有基本计算机操作能力，无需编程经验
- 希望通过实战项目学习 Dota 2 编辑器的开发者

## 最终成果

完成本系列教程后，你将制作出一个包含以下功能的防守类自定义游戏：
- 自定义防守地图，包含多条敌人进攻路线
- 多波次敌人生成系统，难度逐步递增
- 可选英雄及自定义技能
- 防御塔/建筑放置与升级系统
- 物品商店与装备系统
- 自定义游戏 UI
- 音效与视觉特效
