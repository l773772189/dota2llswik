# Dota 2 编辑器入门系列 —— 守家类游戏开发教程

> 本系列教程以制作一个完整的 **守家类（Defense/Survival）自定义游戏** 为目标，带你从零开始，一步一步完成整个游戏的开发与发布。
>
> 📖 编写原则详见 [课程定位与编写原则（备忘录）](./COURSE_GUIDELINES.md)

## 你需要准备什么？

- 一台能运行 Dota 2 的电脑
- 对 Dota 2 自定义游戏感兴趣的热情
- **不需要**任何编程经验，本教程全程以配置和编辑器操作为主

## 这套教程的特点

- ✅ **零编程基础即可上手**：绝大部分内容通过编辑器操作和配置文件完成，不教编程
- ✅ **少量必要代码直接复制粘贴**：个别功能（如刷兵逻辑）会提供现成代码，复制即用，只讲用途不讲语法
- ✅ **对新手极度友好**：每一步都写得清清楚楚，不跳步骤，不省略操作
- ✅ **每课一个知识点**：每节课 5~10 分钟，学一个小知识点，看到一个小成果
- ✅ **全流程体验**：从安装工具到发布上架，走完一个自定义游戏的完整生命周期

## 最终成果

完成全部教程后，你将拥有一个可以发布到 Steam 创意工坊的守家类自定义游戏，包含：

- 🗺️ 一张精心设计的防守地图，有敌人进攻路线和玩家防守区域
- 👾 多波次敌人自动刷新，难度逐步递增，包含 Boss 关卡
- 🦸 可供选择的自定义英雄，各有不同技能
