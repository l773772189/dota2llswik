# P08E04：配置物品合成和击杀奖励

> 设置合成配方让小装备组合成大装备，再给每种敌人配上击杀金币奖励

## 这节课你将完成
- ✅ 配置物品合成配方（比如：两把铁剑合成一把利刃）
- ✅ 为每种敌人设置击杀金币奖励
- ✅ 理解金币经济循环：打怪赚金 → 买装备 → 打更强的怪

## 操作步骤

### 第一步：理解合成配方的原理
<!-- TODO: 用通俗语言解释合成系统
  - 合成就是"几件小物品组合成一件更强的大物品"
  - 比如：铁剑 + 铁剑 = 利刃（攻击力比两把铁剑加起来还高）
  - 玩家需要先买齐所有材料，再花一笔合成费就能自动合成
  - 这让游戏有了"攒钱升级装备"的乐趣 -->

> ✅ **检查点**：你理解了合成的概念——用小装备组合成更强的大装备

### 第二步：创建合成后的高级物品
<!-- TODO: 在 npc_items_custom.txt 中添加高级物品

  - ItemCost 设为合成总价
  - 设置 ItemRecipe 和 ItemRequirements 字段
  - 指定需要 2 个 item_iron_sword 作为材料 -->

> ✅ **检查点**：你的配置文件中有了高级物品 `item_sharp_blade`，并且标注了需要两把铁剑合成

### 第三步：配置合成配方条目
<!-- TODO: 创建合成配方的配置条目

> ✅ **检查点**：合成配方配置完成，当玩家拥有两把铁剑并购买配方后，自动合成为利刃

### 第四步：为敌人配置击杀金币奖励
