  - "键"（Key）是一个名字，比如 "MovementSpeed"，表示"这是什么属性"
  - "值"（Value）是对应的数据，比如 "300"，表示"这个属性等于多少"
  - 键和值之间用空格或 Tab 键隔开
  - 一组相关的键值对用花括号 { } 包起来，表示它们属于同一个东西
  - 花括号可以嵌套，就像文件夹里面还有文件夹 -->
