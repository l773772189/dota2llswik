# P05E04：配置敌人的攻击行为

> 让敌人知道该攻击谁、攻击多远、是否自动攻击

## 这节课你将完成
- ✅ 配置敌人的攻击类型（物理攻击 / 魔法攻击）
- ✅ 设置仇恨范围（Aggro Range），决定敌人多远开始追击
- ✅ 配置自动攻击行为，让敌人主动出击
